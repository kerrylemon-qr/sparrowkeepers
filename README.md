# Sparrowkeepers — QR site

Companion site for **Sparrowkeepers** by Kerry Lemon, reached by the QR codes on the bollards.

- Address: **https://qr.kerrylemon.co.uk/sparrowkeepers** (served via the `qr.kerrylemon.co.uk` hub repo)
- Status: holding page, so the QR can be tested end to end. The full site will follow the same approach as `portal` (content in JSON, accessible, app-style navigation).
- The repo name must stay lowercase `sparrowkeepers`, because it *is* the address the printed QR points to.
